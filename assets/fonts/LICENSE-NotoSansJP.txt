Noto Sans JP (Regular) — assets/fonts/NotoSansJP.ttf
====================================================

このディレクトリのフォントは、ラベルPDF（QR + 備品コード + 品名）に
日本語を印字するために Go バイナリへ embed する。

  ファイル      : NotoSansJP.ttf
  元のファイル名: static/NotoSansJP-Regular.ttf
  フォント名    : Noto Sans JP Regular
  バージョン    : Version 2.004-H2 (Google Fonts 配布 v56)
  サイズ        : 5,472,784 bytes
  SHA-256       : d930d5d52d15231c283089760f84584272ad5e37e14607ba0d19c798e7a9caec

入手元
------
Google Fonts の "Noto Sans JP" 配布物に含まれる static 版 TTF。
配布マニフェスト:
  https://fonts.google.com/download/list?family=Noto%20Sans%20JP
実ファイルの直リンク（上記マニフェストの fileRefs に載っている URL）:
  https://fonts.gstatic.com/s/notosansjp/v56/-F6jfjtqLzI2JPCgQBnw7HFyzSD-AsregP8VFBEj75vY0rw-oME.ttf
ファミリのページ:
  https://fonts.google.com/specimen/Noto+Sans+JP

注意: `https://fonts.google.com/download?family=Noto+Sans+JP` は現在 zip ではなく
HTML を返す。取り直すときは上の `download/list` を叩き、
`fileRefs` の `static/NotoSansJP-Regular.ttf` の URL を使うこと。
URL 中の `v56` とハッシュは Google 側の更新で変わるため、直リンクを決め打ちにしない。

なぜ static 版でなければならないか
----------------------------------
go-pdf/fpdf の AddUTF8FontFromBytes は、TrueType アウトライン（glyf テーブル）を持つ
**静的な** TTF しか読めない。次はいずれも使えない。

  - OTF / CFF アウトライン（先頭 4 バイトが "OTTO"）
    Noto Sans CJK の公式配布物（notofonts/noto-cjk）は多くがこれ。
    拡張子を .ttf に変えても動かない。
  - バリアブルフォント（fvar テーブルを持つもの）
    google/fonts リポジトリにある `NotoSansJP[wght].ttf` や、上のマニフェストの
    `NotoSansJP-VariableFont_wght.ttf` はこれ。

差し替えるときは、先頭 4 バイトが `00 01 00 00` で、`glyf` があり、
`CFF ` と `fvar` が無いことを必ず確認する。
